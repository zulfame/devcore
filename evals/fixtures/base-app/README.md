# Kalkulator Harga

Aplikasi kecil untuk menghitung harga pesanan: total belanja dan diskon persentase.

## Menjalankan test
```bash
python3 -m unittest discover -s tests -t .
```

## Struktur
- `app/pricing.py` — perhitungan total dan diskon
- `app/users.py` — pendaftaran pengguna
- `app/config.py` — konfigurasi aplikasi
- `tests/` — test unit
